## Why I made this
I wanted to tell the world about my skills, so I brainstormed and created this blog 'from the ground up'.

## Features
- Built with Astro
- Made from HTML, CSS & JS
- Built-in Admin Panel for publishing and managing posts
- Zero plugins or addons such as RSS, Joomla, or Wordpress

# Challenges
Although I managed to create this blog, I encountered problems with setting the blob, styling the posts, and the panel, as they were crucial to power this website.

# How to access website?

As of now, the only way to access the site is by `git clone`:

```

cd V_blog
```
